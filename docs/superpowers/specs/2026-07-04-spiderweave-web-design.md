> 版本：v1.0-web MVP  
> 日期：2026-07-04

## 一、技术选型

| 层面 | 方案 | 原因 |
|------|------|------|
| 框架 | React 18 + Vite | 生态成熟、面试认可度高、部署简单 |
| Canvas | SVG 内联 | 节点天然可点击、缩放平移简单、MVP 节点数少性能足够 |
| 路由 | 无（state 切换） | 仅 2 个页面，不引入 react-router |
| 状态管理 | React Context | 全局蜘蛛状态 + 网数据 |
| 持久化 | localStorage | 零后端、即时可用、面试展示无需注册 |
| 样式 | 纯 CSS | 无 UI 库，保持极简 |
| 部署 | Vercel / Netlify | 免费、一键部署、公开 URL |
| 版本管理 | Git | 本地迭代 |

## 二、架构

### 项目结构

```
spider/
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── main.jsx
    ├── App.jsx
    ├── contexts/
    │   └── SpiderContext.jsx   # 蜘蛛状态 + 网数据（全局）
    ├── hooks/
    │   ├── useSpiderState.js   # 蜘蛛饥饿/状态计算
    │   └── useLocalStorage.js  # localStorage 读写封装
    ├── pages/
    │   ├── HomePage.jsx        # 首页：蜘蛛特写 + 打招呼
    │   └── WebDetailPage.jsx   # 网详情：SVG 蛛网 + 步骤列表
    ├── components/
    │   ├── Spider.jsx          # SVG 蜘蛛（3 种状态）
    │   ├── GreetingBubble.jsx  # 打招呼气泡
    │   ├── WebSvg.jsx          # SVG 蛛网画布（只读展示，含缩放平移）
    │   ├── ThreadNode.jsx      # 丝线节点（骨架上的点）
    │   ├── CreateWebModal.jsx  # 创建新网的弹窗
    │   ├── StepList.jsx        # 步骤列表（勾选完成）
    │   └── StatusBadge.jsx     # 蜘蛛状态标签
    └── styles/
        └── global.css          # 全局样式（暗色主题）
```

### 页面路由

用 App.jsx 内的 state 切换，无路由库：

```
currentPage === 'home'      → <HomePage />
currentPage === 'webDetail' → <WebDetailPage />
```

### 数据流

```
localStorage
    │
    ▼
SpiderContext
    ├── spider: { hunger, lastFedAt }
    ├── webs: GoalWeb[]
    │     └── threads: { title, status, skeletonIndex, layerIndex }
    │
    └── 计算属性：
        ├── spiderState    ← hunger > 50 → active, 1~50 → hungry, 0 → shrunk
        └── greeting       ← 根据 spiderState 随机取文案
```

## 三、数据模型

```js
// 蜘蛛
spider = {
  hunger: 0~100,         // 100 = 饱，0 = 极度饥饿
  lastFedAt: timestamp   // 上次完成步骤的时间
}

// 目标网（最多 3 张）
goalWeb = {
  id: string,
  title: string,
  createdAt: timestamp,
  threads: [
    {
      id: string,
      title: string,
      status: 'todo' | 'done',
      skeletonIndex: 0~5,   // 挂在哪根骨架上
      layerIndex: number,    // 从中心向外第几层
      completedAt: timestamp?
    }
  ]
}

// 全局
appData = {
  spider: Spider,
  webs: GoalWeb[]
}
```

## 五、核心机制

### 步骤 → 丝线映射

- 网的骨架：6 根线从中心向外发散（角度均匀分布：0°, 60°, 120°, 180°, 240°, 300°）
- 步骤按创建顺序依次分配到骨架（skeletonIndex = 步骤序号 % 6）
- 每根骨架上的步骤按分配顺序向外排列（layerIndex 递增）
- 完成步骤 → 该位置的丝线从灰色虚点变成银白实线

### 压力系统

```
hunger 初始值 = 100

每次打开页面时计算：
  deltaHours = (now - lastFedAt) / 3600000
  hungerLoss = Math.floor(deltaHours / 24) * 34
  hunger = Math.max(0, 100 - hungerLoss)

状态判定：
  hunger > 50  → active  (活跃)
  hunger 1~50 → hungry  (饥饿)
  hunger = 0   → shrunk  (萎缩)

完成一个步骤：
  hunger = Math.min(100, hunger + 20)
  lastFedAt = now

网破损（独立于饥饿）：
  daysSinceLast = (now - lastFedAt) / 86400000
  < 3 天  → 网完整
  3~7 天  → 骨架末端断裂（虚线 + 抖动动画）
  > 7 天  → 只保留中心一小圈，外圈半透明
```

### 打招呼文案池

```js
const greetings = {
  active: [
    '今天想织哪根丝？',
    '网越来越密了，真好看',
    '我吃饱了，又有力气了',
    '你来了！继续织网吧',
    '今天状态不错哦'
  ],
  hungry: [
    '有点饿了…能织一根丝给我吗？',
    '等你好久了',
    '再不动手，风要吹断我的网了',
    '网好像有点松了…',
    '今天能织一根丝吗？就一根'
  ],
  shrunk: [
    '我快撑不住了',
    '网破了好多洞……',
    '你终于回来了',
    '我还在这里等你',
    '再不来，网就只剩骨架了'
  ]

```
