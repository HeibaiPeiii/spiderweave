## 执行步骤

### 第一步：注册微信小程序账号（~40 min）

1. 打开 https://mp.weixin.qq.com → 点击"立即注册" → 选择"小程序"
2. 准备一个未注册过微信公众平台的邮箱
3. 按流程填写信息 → 邮箱验证 → 选择**「个人」主体
4. 上传身份证 + 微信扫码绑定管理员 → 提交
5. 登录后进入「开发 → 开发管理 → 开发设置」，找到并记录 **AppID**

> 个人主体无需营业执照、无需对公账户。注册时填的微信号即为管理员。

### 第二步：安装微信开发者工具（~15 min）

1. 打开 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 下载 Windows 稳定版
3. 安装完成后打开，微信扫码登录

### 第三步：创建第一个项目（~30 min）

1. 开发者工具首页 → "创建小程序"
2. 填入 AppID
3. 项目目录选择 `D:\cc\spider`
4. 模板选择「不使用云开发」
5. 创建完成 → 看到默认模板页面

### 第四步：理解项目结构（~30 min）

四个核心文件类型：

| 文件 | 作用 | 对应已有知识 |
|------|------|-------------|
| `.json` | 页面/应用配置 | 无 |
| `.wxml` | 页面结构 | ≈ HTML |
| `.wxss` | 页面样式 | ≈ CSS |
| `.js` | 页面逻辑 | ≈ JavaScript |

### 第五步：真机预览（~20 min）

1. 开发者工具顶部点击「预览」
2. 手机微信扫码
3. 小程序在手机上打开
