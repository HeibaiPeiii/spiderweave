> 版本：v1.0 MVP  
> 作者：应届生 PM 作品

## 一、产品定位

### 一句话定位

用蜘蛛结网的压力机制，把「要做的」变成「正在做的」。通过一只电子蜘蛛和一
张会破损的网，给拖延症用户一个"不做就会失去"的温和压力。

### 核心差异化

| 维度 | 竞品（Forest / 番茄钟 / Habitica） | SpiderWeave |
|------|-----------------------------------|-------------|
| 心理模型 | "管好自己" — 外部规则驱动 | "蜘蛛也需要织网" — 共情 + 压力驱动 |
| 视觉反馈 | 数字 / 进度条 / 图表 | 蛛网从无到有的生长过程 |
| 目标创建 | 用户自己填写 | 后期：AI 对话生成；MVP：用户手动拆解 |
| 失败处理 | 扣分 / 中断 / 枯萎 | 网破损 + 蜘蛛饥饿 — 画面本身是提醒 |

### 目标用户

- 有拖延倾向、需要外部压力驱动的大学生 / 职场新人
- 对电子宠物 / 养成类产品有好感的人群
- 试过番茄钟但"放着就不打开了"的用户

### 参考产品

- **Forest**：极简风格、专注完成时刻的满足感
- **电子宠物（拓麻歌子）**：养成情感连接、打开频率驱动

## 二、核心概念与压力机制

### 三个核心元素

```
蜘蛛 = 用户的分身，替你感受压力
丝线 = 每一个待完成或已完成的步骤
蛛网 = 所有步骤织在一起的结果
```

### 压力机制（自然规律，不是惩罚）

| 机制 | 触发条件 | 视觉表现 |
|------|---------|---------|
| 蜘蛛饥饿 | 连续 24h 未完成任何步骤 | 蜘蛛缩小、没精神 |
| 丝线崩断 | 连续 72h 未操作 | 网边缘开始破损，断丝飘动 |
| 网大面积空洞 | 超过 7 天未操作 | 只剩最初几根骨架 |

| 恢复条件 | 效果 |
|---------|------|
| 完成任意步骤 | 蜘蛛恢复活力、破损停止扩散 |
| 连续完成 | 网变得更完整、蜘蛛体型变大 |

**设计原则**：压力不来自"系统告诉你你不行"，而来自"你看到蜘蛛在等你"。用户打
开小程序看到一只缩在角落的蜘蛛 + 残破的网，这个画面本身就是最有效的提醒。

## 三、用户核心流程

```
打开小程序
    │
    ▼
首页 — 蜘蛛特写 + 打招呼
  │  "今天看到你有一根丝还没织完，要动手吗？"
  │  [ 继续织网 ]  [ 建新网 ]  [ 查看习惯网 ]
  │
  ├── 场景 A：创建新网（单一目标）
  │     ├── 用户输入目标名称
  │     ├── 用户手动拆解步骤
  │     ├── 为每个步骤设置截止时间（可选）
  │     ├── 确认 → 生成一张新的蛛网
  │     └── 最多同时 3 张单一目标网
  │
  ├── 场景 B：完成步骤（织丝）
  │     ├── 在蛛网上点击对应位置
  │     ├── 确认完成
  │     ├── 播放织丝动画（MVP：静态绘制丝线）
  │     └── 蜘蛛状态回升
  │
  └── 场景 C：查看习惯网
        ├── 日常习惯用独立页面管理
        ├── 每日勾选完成
        └── 同一只蜘蛛管理全部网，习惯网的完成也会喂饱它
```

### 首页设计决策

- **焦点：蜘蛛特写**而非全局网视图
- **每次打开都打招呼**：蜘蛛是电子宠物，有简短对话
- **场景切换**：单一目标网和习惯网是分开的两张网，但由同一只蜘蛛守护——完成任一类型的步骤都能喂饱它

## 四、功能范围

### MVP（v1.0）— 必须

| 模块 | 功能 | 优先级 |
|------|------|--------|
| 蜘蛛 | 首页展示、状态变化（活跃/饥饿/萎缩） | P0 |
| 蜘蛛 | 每次打开打招呼（预设文案池随机） | P0 |

> **MVP 打招呼文案池**（约 20 条，按蜘蛛状态分类）：
> - 活跃态：「今天想织哪根丝？」「网越来越密了，真好看」「我吃饱了，又有力气了」
> - 饥饿态：「有点饿了……能织一根丝给我吗？」「等你好久了」「再不动手，风要吹断我的网了」
> - 萎缩态：「我快撑不住了」「网破了好多洞……」「你终于回来了」
| 目标网 | 手动创建目标 + 拆解步骤 + 设置截止时间 | P0 |
| 目标网 | 点击步骤 → 确认完成 → 丝线绘制 | P0 |
| | 网视图：点击丝线节点 → 弹出确认浮层 | |
| | 列表视图（备选）：点击步骤卡片 → 勾选完成 | |
| 目标网 | 最多同时 3 张网 | P0 |
| 压力系统 | 蜘蛛饥饿倒计时（24h） | P0 |
| 压力系统 | 网破损可视化（72h+） | P0 |
| 压力系统 | 完成步骤后状态恢复 | P0 |
| 习惯网 | 日常习惯管理（独立页面） | P0 |
| 习惯网 | 每日勾选 + 独立进度 | P0 |

### v1.1 — 重要

| 模块 | 功能 | 优先级 |
|------|------|--------|
| 动画 | 织丝动画（Canvas 缓动） | P1 |
| 蜘蛛 | 外观随状态变化（体型/表情） | P1 |
| AI | 接入 AI 对话生成目标计划 | P1 |
| 历史 | 已完成网的画廊 | P1 |

### 不做

- 排行榜、好友 PK、积分商城
- 社交分享（v2.0 考虑）
- 推送通知（用画面本身代替通知）

## 五、数据模型

```
User（用户）
  ├── Spider（蜘蛛）
  │     ├── name: string          // 默认"小蛛"
  │     ├── state: active/hungry/shrunk
  │     ├── hunger: 0~100         // 0 = 极度饥饿
  │     └── lastFedAt: timestamp
  │
  ├── GoalWeb[]（目标网）× 最多 3
  │     ├── title: string
  │     ├── createdAt: timestamp
  │     ├── deadline: timestamp?
  │     ├── status: active/done/abandoned
  │     ├── breakage: 0~100       // 破损程度
  │     └── threads: Thread[]
  │           ├── title: string
  │           ├── status: todo/in_progress/done
  │           ├── deadline: timestamp?
  │           ├── position: number // 在网上的位置
  │           └── completedAt: timestamp?
  │
  └── HabitWeb（习惯网）× 1
        ├── habits: Habit[]
        │     ├── name: string
        │     ├── frequency: daily/weekly-N
        │     └── timeSlot: morning/afternoon/evening/any
        └── records: DailyRecord[]
              ├── date: string
              ├── habitId: string
              └── status: done/skipped/missed
```

## 七、视觉与交互

### 整体风格

| 维度 | 方向 |
|------|------|
| 色调 | 深色底色（暗蓝/深灰），蛛丝为银白半透明 |
| 蜘蛛 | 风格化可爱但不幼稚，写实感低 |
| 字体 | 细体，文字克制，让画面说话 |
| 动效 | 织丝动画是体验核心（v1.1） |

### 参考：Forest 的启发

- 视觉重心始终只有一个
- 极简，无冗余信息
- 完成时刻的仪式感是用户回来的动力
- 画面本身是最高效的提醒

### 网的手势操作（v1.1）

| 手势 | 作用 |
|------|------|
| 单指拖动 | 平移视角 |
| 双指缩放 | 放大/缩小 |
| 点击空白 | 添加新步骤 |
| 点击丝线 | 查看步骤详情 |

## 八、技术方案

### 技术选型

| 层面 | 方案 | 原因 |
|------|------|------|
| 前端 | 微信原生 WXML/WXSS/JS | 学习成本低，你已有 HTML/CSS/JS 基础 |
| Canvas | 微信原生 Canvas 2D API | 蛛网绘制核心 |
| 后端 | 微信云开发 | 免服务器、自带数据库、云函数 |
| 登录 | 微信一键登录 | 无需注册流程 |
| AI（v1.1） | DeepSeek / 通义千问 API | 成本低、中文好 |

### MVP 降级策略

- 织丝动画 → 静态 Canvas 绘制（点击完成 = 画一根线）
- AI 对话 → 用户手动填目标 + 拆步骤
- 蜘蛛动态表情 → 三张静态图切换（活跃/饥饿/萎缩）

## 九、上架流程

```
① 注册小程序账号
   └── 需：未注册过的邮箱、身份证、微信绑定银行卡

② 完善信息
   ├── 名称：蛛网 SpiderWeave
   ├── 类目：工具 → 效率
   └── 简介：用蜘蛛结网的仪式感，告别拖延

③ 开发调试
   └── 微信开发者工具 → 真机预览

④ 提交审核
   └── 类目"工具-效率"审核较快，1~7 个工作日

⑤ 发布上线
   └── 可设灰度发布再全量
```

**⚠️ 注意**：个人主体不能接入 AI 生成内容。v1.1 接入 AI 对话时，需注册企业主体
（个体工商户即可）。
